databricks.sirens.connectors.common module#

common methods for connectors that rely on API connectivity.

Collecting remote API data happens on a driver node, but spark.read does not support reading from here. Sirens writes data locally to a temp file then atomically moves the temp file to cloud storage. Either a batch or streaming dataframe can then be generated from there.
