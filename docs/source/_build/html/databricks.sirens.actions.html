databricks.sirens.actions.splunk_soar module#

Splunk SOAR API Module.

Author:

Derek King. 01-Nov-23

Version: 1.0

the alert_handler reads alerts/records from a delta table and sends them to a phantom / Splunk SOAR instance using the alerts.yaml & splunk_soar/action.yaml.

map your alert schema to the Phantom RESTAPI fields using action.yaml.

With the action.yaml and alerts.yaml configured, process them using .. code-block:: python3

from databricks.sirens.alertmanager import AlertHandler alert_processor = AlertHandler(database=”<alert_database>”, tables=[“<list of tables to process>”], since=”INTERVAL 1 day”) alert_processor.process_alerts()

You can interact directly with the module by importing SoarAPI .. code-block:: python3

from databricks.sirens.actions.splunk_soar import SoarAPI SoarObj = SoarAPI(server=<server>, auth_token: str = None, verify_ssl=[True|False]) # optionally create a container result = SoarObj.create_container(name”test_event”, **kwargs) if result.status:

container_id = result.data[‘id’]

# add artifacts (either specify a container_id or containers will be created) result = SoarObj.add_artifacts(df)
