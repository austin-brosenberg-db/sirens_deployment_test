databricks.sirens.threathunting.functions.get_hunt_result(hunt_name: str = None, time_start: str = None, time_end: str = None, run_id: str = None, command_name: str = None, database: str = 'hunting_dbx', hunt_index: str = 'threathunt_index', hunt_table: str = 'threathunt_results') → List[DataFrame] | None#
filter the threat hunt index and get the original results back as a list of DataFrame(s).

One DataFrame per captured analytic command is returned as they appeared in the original job.

You can then assign a new variable to each array index to triage & subsequently work on the original captured data.

Note: Although all args are optional, you have to supply something!

See show_hunt_results() if you want to see the original captured output only.

Parameters:

  • hunt_name (str, optional) – name of hunt to filter for, defaults to None

  • time_start (str, optional) – date/time of the hunt start, defaults to None (ex: 01-13-2024 13:00:00)

  • time_end (str, optional) – date/time of the hunt end, defaults to None (ex: 01-13-2024 14:00:00)

  • run_id (str, optional) – run_id of the hunt, defaults to None

  • command_name (str, optional) – a specific analytic command that is captured, defaults to None

  • database (str, optional) – _description_, defaults to BackendDefaults.DATABASE

  • hunt_index (str, optional) – _description_, defaults to BackendDefaults.INDEX_TABLE

  • hunt_table (str, optional) – _description_, defaults to BackendDefaults.HUNT_TABLE

  • output_format (OutputFormat, optional) – specify the output format as .asObject, asJSON, asDataFrame, defaults to OutputFormat.asDataFrame

Returns:

a list of original Dataframes that can be assigned to a new variable, and subsequently worked.

Return type:

Union[List[DataFrame], None]
