  • window_duration (str) – A string specifying the width of the window, e.g. 10 minutes, 1 second

  • wait_for_late_data (str) – .withWatermark - the minimum delay to wait to data to arrive late, relative to the latest record that has been processed in the form of an interval (e.g. “1 minute” or “5 hours”)

  • start_time (_type_, optional) – The offset with respect to 1970-01-01 00:00:00 UTC with which to start window intervals, defaults to None
